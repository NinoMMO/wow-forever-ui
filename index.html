My WoW Forever UI for Steam Deck & Handhelds

EllesmereUI profile + Edit Mode layout, built for controller play on the Steam Deck and other handhelds. You need both strings for your device.

How to import (you need the EllesmereUI addon from CurseForge first)
  1. Press COPY on the EllesmereUI profile. In game: EllesmereUI → Profiles → Import Profile → paste (Ctrl+V) → name it → Import.
  2. Press COPY on the Edit Mode layout. In game: Edit Mode → Layout → Import → paste → name it → Import.
  3. Log out once so it saves.

No keyboard on the Deck? Bind Ctrl+V to a back button and paste with one press: watch the short.
