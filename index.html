My WoW Forever UI for Steam Deck & Handhelds

EllesmereUI profile + Edit Mode layout, built for controller play on the Steam Deck and other handhelds. You need both strings for your device.

How to import (you need the EllesmereUI addon from CurseForge first)
  1. Press COPY on the EllesmereUI profile. In game: EllesmereUI → Profiles → Import Profile → paste (Ctrl+V) → name it → Import.
  2. Press COPY on the Edit Mode layout. In game: Edit Mode → Layout → Import → paste → name it → Import.
  3. Log out once so it saves.

No keyboard on the Deck? Bind Ctrl+V to a back button and paste with one press: watch the short.

Stuck? Common fixes
  • Edit Mode import greyed out or not applying: turn on Gamepad Mode (Options → Gamepad → Gamepad Support).
  • No download button on battle.net: set display scaling to 100% or use Firefox.
  • CurseForge finds Retail, not Forever: skip the auto scan, add the _forever_ folder by hand (4:55).
  • No "show hidden files" menu (5:36): press Ctrl+H in that window.
  • 4 spell icons you can't move: Options → Advanced → untick Enable Cooldown Manager.
  • EllesmereUI window won't close with the controller: tap the X top right on the touch screen.
  • Binding spells: hover one in the spellbook and press X. Hold R1, L1, R2 or L2 for 8 more slots each.
  • UI looks mixed up after the import: rename your WTF folder to WTF_old, restart WoW, import again.
